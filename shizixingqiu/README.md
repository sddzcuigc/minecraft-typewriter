# 识字星球 · 3500 汉字版

网页：https://shizixingqiu-sddzcuigcs-projects.vercel.app

## 本阶段功能
- **3500 字**本地字库，拼音（包含多音字候选）、笔画、部首、按常用程度筛选。
- 支持汉字、无声调拼音、已人工编辑词语检索，48 字分页。
- 已编辑联想图标、简单词语与例句的一批基础汉字；其他字明确显示“暂无专属插画/释义”，不填假内容。
- 朗读按钮：使用系统 Web Speech API，是否能离线朗读取决于浏览器和本机中文语音包。
- 拼音打字闯关：仅自动出单读音汉字，避免多音字脱离词语语境的歧义。
- 五笔86：只收录并展示 8 个已核验键名字根，不把它们的四连击规则用到普通汉字。
- 学习进度与错字本：浏览器 localStorage（不跨浏览器同步）。

## 目录
- index.html: 网站入口
- style.css: 本地样式
- data.js: 3500 字离线字库（纯 JS，不依赖 fetch）
- app.js: 页面与练习逻辑
- ATTRIBUTION.md: 数据来源和许可证

## 运行
把整个 shizixingqiu 目录下载下来，双击 index.html 即可。无需 Node、云端数据库或 CDN。内网静态文件服务器也可直接托管。

## 验收
1. 打开首页检查顶部显示 3500 字，进入“汉字字库”分页、搜索 shui/水/山。
2. 进入打字闯关，输入正确拼音会累计分数，错误加入错字本，再答对移出。
3. 进入五笔字根练习，核验水=IIII、火=OOOO、木=SSSS、口=KKKK、日=JJJJ、月=EEEE、人=WWWW、山=MMMM。
4. 断网刷新/直接 file:// 打开，仍能查字与玩打字游戏。
5. 刷新同一浏览器后，进度仍在。
