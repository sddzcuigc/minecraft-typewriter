# 识字星球 · 3500字离线学习版

在线版：https://shizixingqiu-sddzcuigcs-projects.vercel.app

GitHub：https://github.com/sddzcuigc/minecraft-typewriter/tree/main/shizixingqiu

## 本次新增（V2 学习模块）
- **拼音打字练习**：3500字单字随机出题 + 30个原创词语；接受声调符号和数字声调（如 shān / shan1）；可切换是否强制声调；提供声母、韵母、整体认读音节速查表。
- **记忆曲线**：本地间隔重复；“忘记”10分钟后重试，“模糊”短间隔，“记住”逐步延长；记录复习时间和熟悉度。
- **硬笔书写**：田字格描红/临摹，支持鼠标、触屏和触控笔；可清空并导出练习图片。
- **笔顺演示**：内置8个常见字的笔画数据；其他字符在线首次请求并缓存到 IndexedDB，之后可离线使用。笔顺数据来源及许可见 STROKE-DATA-LICENSE.txt。
- **间架结构口诀**：整理独体、左右、上下、包围、品字等10类结构的儿童练字提示。提示为教学辅助口诀，不是国家标准原文。
- **记忆工坊**：形旁提示、拆字观察、故事/动作联想、谐音联想和记忆宫殿；用户自定义内容仅保存在本机。
- **教材例句**：可按年级、学期、课次录入自备教材短句，在本机按汉字检索。另有明确标注的原创练习句和人教社官网入口；不批量抓取或再分发人教版课文。
- **图画搜索**：联网搜索 Wikimedia Commons；只展示元数据可识别且筛选为 CC BY、CC BY-SA、CC0 或公有领域的结果；显示作者、许可与来源页；用户点击后缓存到 IndexedDB，供断网查看。

## Go 便携启动器

项目目录新增 `main.go` 与 `go.mod`，仅依赖 Go 标准库，静态资源通过 `embed` 编入单个可执行文件，不需要 Node.js、npm、CDN 或在线运行时。启动后默认监听 `127.0.0.1:18765` 并打开浏览器；如需内网访问，可显式运行 `-listen 0.0.0.0:18765`，程序会列出本机 IPv4 地址。内网开放时请配置防火墙，只在可信局域网使用。

GitHub Actions 会在每次更新本项目时自动生成 Windows x64、Linux x64、macOS Apple Silicon 启动器，以及源码 ZIP；在仓库 Actions 页面下载对应产物，保留30天。手工构建命令如下。

Windows amd64：

```powershell
go build -trimpath -ldflags="-s -w" -o dist/shizixingqiu-windows-amd64.exe .
```

macOS Apple Silicon：

```bash
GOOS=darwin GOARCH=arm64 go build -trimpath -ldflags="-s -w" -o dist/shizixingqiu-darwin-arm64 .
```

Linux amd64：

```bash
GOOS=linux GOARCH=amd64 go build -trimpath -ldflags="-s -w" -o dist/shizixingqiu-linux-amd64 .
```

无图形界面或服务器环境可加 `-open=false`。更换操作系统/CPU 架构时需重新编译对应二进制。

## 离线策略
- 核心页面、3500字字库、样式、拼音练习、记忆数据、手写画布、精选笔顺数据均在本地。
- 图片搜索和未缓存字符的笔顺首次加载需要网络。选中的图片和首次请求的笔顺会写入浏览器 IndexedDB。
- 浏览器 localStorage 保存学习进度、错字本、记忆曲线、用户记忆线索和用户导入的教材短句。
- 无 CDN、无第三方 JS 运行时、无后端数据库。双击 index.html 可运行核心功能；推荐通过 Go HTTP 启动器打开，以获得稳定的浏览器存储与跨域请求行为。首次通过 localhost 加载时，Service Worker 会缓存核心静态文件，后续可离线刷新。
- 不同浏览器/设备的数据不会自动同步。更换设备前需自行备份浏览器数据。

## 重要边界
- 字库拼音含多音字候选；拼音闯关自动出题只选单读音字。词语模式为项目自编短词组，不代表人教版课文。
- 笔顺数据：离线内置覆盖8字，其余字符按需联网下载；数据源为 Hanzi Writer Data / Make Me a Hanzi 衍生数据，采用 Arphic Public License。不是对全部3500字逐字人工校验的国家标准证明。
- 图片搜索的许可证元数据由 Wikimedia Commons 页面提供。自动过滤只能降低风险，不能代替用户检查原始文件页及许可条款。
- 人教版教材文字、图片和数字资源受版权保护。此应用不批量抓取或打包课文。用户可把合法持有的短句导入本机学习；教材电子版以人教社官方入口为准。
- 结构口诀是原创/整理的通用练字提示，字形布局有例外，不应机械套用。
- 五笔86仍只有此前8个已核验键名字根，不代表完整五笔拆分功能。

## 运行和验收
1. 断网打开 index.html：检查3500字字库、拼音练习（单字模式）、书写画布、记忆工坊、间隔复习。
2. 拼音练习分别输入带声调形式和数字声调形式；切换“必须输入声调”。
3. 记忆曲线加入10个新字，分别点击“忘记/模糊/记住”，刷新后检查记录与到期时间。
4. 硬笔书写选择“一、二、十、人、入、八、口、山”，演示笔顺、描红、自由书写并导出PNG。
5. 联网搜索图片，缓存后断网，检查离线图册是否仍能显示并保留许可信息。
6. 教材例句录入一条自备短句，按其中的汉字检索，刷新后检查仍在本机。
7. 用户数据不上传服务端；清除浏览器站点数据会清除本地进度和缓存。

## V2.2：字义、谐音与字源联想

新增 3500 字离线字形联想卡，含部首/结构提示和部分实物图标，全部是浏览器本地生成的 SVG 示意图，不等同于 3500 幅人工绘制或 AI 生成的语义插画。

开源词典可匹配 **3495** 字现代辅助释义；CC0 公有领域《说文解字》语料按字形匹配 **2176** 条（其中部分由繁体字匹配）。另外五字“岖、玫、茉、啤、徘”缺少可靠现代义项，会明示待补而非编造。因《说文》主要面向篆书，现代字义、古籍原文和创意联想分别展示，尤其注意“后/後”等古今字形与义项冲突。

谐音模块根据字库中带声调拼音查找同音字，自动提出记音练习；不能保证每个字有可靠谐音故事，不将同音说成同义。可继续由老师逐字审核、编辑并覆盖。生成器位于 `tools/build_notes.py`，GitHub Actions 工作流 `build-notes.yml` 从固定上游版本构建 `notes.js`。完整来源见 ATTRIBUTION.md。


## V2.3：本地AI老师课堂 MVP

新增「AI老师」入口。课堂以本地规则教学状态机运行，不调用云端模型，不需要账号、网络或API Key。每节课包含：课前说明、字形/读音/释义讲解、例句和记忆联想、独立拼音选择题、错题反馈和继续学习。课堂进度、答题记录和复习到期时间保存在当前浏览器 localStorage。

- 教学数据优先读取现有3500字拼音与 notes.js 释义/《说文》匹配记录；精选常用字另提供儿童化例句和联想。
- 答对后按1、3、7、14、30天递增安排复习；答错10分钟后重新进入待复习池。该算法是轻量规则，不等同于经验证的标准SM-2，也不代表一次答对即可掌握。
- 无在线大模型时可独立教学；当前“AI老师”是产品交互名称，实质是可解释的规则式教学 MVP，并非生成式AI对话教师。后续接本地LLM时，模型只负责讲解建议，题目判分和复习状态仍由本地规则控制。
- 新增 teacher.js，Go embed 启动器已包含该文件；Service Worker 更新至 v5 并缓存课堂脚本。
- 学习数据仅存本机浏览器，不跨设备同步；清理浏览器站点数据前应备份。

### 验收重点
1. 首页出现「AI老师」标签；点击显示课程主页和本地学习统计。
2. 开始课堂进入逐字教学，显示拼音、现代释义、例句和可用的《说文》参考。
3. 点击“我准备好了”进入四选一拼音检测；正确选项会被标记，错误答题会记录错题并设置10分钟复习。
4. 完成5字课堂后更新完成次数；重新打开页面统计仍保留。
5. teacher.js 不依赖外部网络资源；离线运行核心课堂。


## V3.0：识字星球世界化重构

默认入口重构为儿童学习世界：星球主视觉、探索地图、学习统计、芽芽老师入口和学习工具箱。原有汉字字库、拼音闯关、五笔、书写、记忆工坊、课文例句、图片找图等功能保留为二级工具入口。

- 芽芽老师课程：单字观察、拼音/现代义项/生活例句、明确标注的创意记形联想、古籍资料折叠查看。
- 每字挑战按课程位置轮换读音、词语和部首三种检测；即时反馈后才可继续。
- 记录星星能量、初步掌握、错题、复习到期和课程次数，全部保存在本机 localStorage。
- 答对按1/3/7/14/30天排程，答错10分钟后重试。此排程是启发式规则，尚未通过儿童学习效果研究验证。
- 当前为离线规则式教学产品，不冒充生成式AI。没有云端对话、语音识别或自动作文批改。

验收：进入星球主界面；完成逐字讲解和挑战；验证答题反馈与刷新后学习记录保留。移动端双列地图和工具箱自适应。


## V3.1：自适应教学引擎（2026-11-11）

- 新增独立的 \`teacher-engine.js\`：拼音解析、题目生成、错误类型识别、提示策略、二次讲解和复习排程均为纯本地确定性逻辑。
- 题型包括“看字辨音”和“词语补字”。词语题只使用项目已有的精选词语数据；干扰字按笔画数接近原则选取。读音题只使用数据中只有一个读音且通过拼音结构校验的字。多音字不在没有词境的情况下被当作单答案题。
- 第一次答错：不公布答案，先根据声母、韵母、声调或词语语境给提示；第二次答错：展示拆解讲解和精选例句，再换一种题型做迁移检查。
- 首次独立答对：按1、3、7、14、30天递增复习；提示后答对：次日复习；二次讲解后答对或仍答错：10分钟后短复习。连续掌握要求多次独立答对，不把一次猜对当作掌握。
- 从 \`szx_world_v3\` 自动迁移旧学习进度到 \`szx_world_v4\`，不会主动清除旧记录。
- \`app.js\` 将现有精选常用字词语表暴露给本地课堂复用，避免另造一套互相冲突的教学词库。
- Go embed 加入 \`teacher-engine.js\`；Service Worker 缓存版本升至 v7。没有新增 CDN、在线 API、Node 运行时或后端服务。
- 新增 Node 内置断言测试 \`teacher-engine.test.js\`，构建工作流先执行教学引擎测试，再构建 Windows/Linux/macOS 便携启动器。

### 验收边界

该引擎是可解释的自适应规则教学，不是生成式 AI。它可以区分部分拼音混淆、根据词语例句换题型并安排复习，但不能验证孩子是否真正开口朗读，也没有语音识别、笔迹评分或作文理解。拼音解析规则是出题过滤器，不是完整汉语语音学引擎。释义来源仍需逐字校订。
