| 优先级 | 发现 | 证据 | 修复 |

- 覆盖 320/375/768px 的首页和字库、移动导航及文档宽度；375px 首次答错提示、第二次错误讲解、变式题、完成五字课堂、刷新保留结果；320px 拼音/错字本/书写入口；375px JSON 导出、清空、导入并刷新恢复。
- 测试服务启动在 CI 的 localhost，属于浏览器实跑，不是仅解析 DOM 或 CSS。生产/预览站点还需单独核对 HTTP 和静态资源。
- Playwright 虽运行真实 Chromium，但视口模拟**不等于**真机 Safari / 安卓 Chrome / 平板手势实测。

## 不应宣称完成的项目

1. 未经过真实儿童课堂观察、教师逐字校订、学习效果研究。
2. 未完成真实 iPhone Safari、不同品牌安卓浏览器、横屏和平板逐页人工验收。
3. 未建立经确认的逐像素截图基线，现有截图是人工可视检查素材，不是全自动视觉无回归的证明。
4. JSON 仅备份 `szx_world_v4` 课堂记录，其他工具的 localStorage/IndexedDB、图画和笔顺缓存不包含在内。
5. 在线图片搜索与未缓存笔顺需要联网，核心离线课堂不依赖外部服务。

## 发布门槛与回滚

- 代码发布：必须满足教学引擎 + Chromium 6 个用例 + Go 三平台/ZIP 构建通过、Vercel 部署 READY、线上首页及静态脚本 HTTP 200。
- 真机接受：出现无法开课、答错状态错乱、刷新记录丢失、不可消除的横向溢出为 P0，立即撤回生产部署或恢复到上述 V3.2 版本；小型排版问题归类 P1 并限期修复。
- 人工接管：用户可在 GitHub PR 查看 diff、Actions 下载截图；Vercel 保留 V3.2 部署作为回退目标。导入前必须先导出当前记录。
- 决策规则：先证明孩子能完整学习且记录可靠，再扩充视觉效果和 AI 功能。
