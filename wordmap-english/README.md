# 词汇星图 WordMap V5.1.1

## 本轮新增
- 拼音打字练习：显示中文意思、拼音近音钩子和拼写块，键入英文时即时判定，不需要提交按钮；拼音练习统计独立记录，不冒充无提示掌握等级。
- 拼音记忆法：把拼写块与汉语近音联想并列展示；所有近音均标注“近似音”，先听标准英语发音，避免把中文近音当成英语音标。
- 图片词典：在线使用 Wikimedia Commons API 搜索图片，展示原始文件页、作者和许可信息；用户选择后保存图片 Blob 到 IndexedDB。
- 离线图片：图片缓存保存在本机；支持导出/导入 JSON 图片包。在线搜索需要网络，文字、练习、记忆卡和已缓存图片可断网使用。
- 记忆中心：展示示意遗忘曲线、当前到期复习队列和 1/3/7/14/30 天间隔；曲线为教学示意，复习队列取自本机真实学习记录。
- 谐音空间：每个词可编辑拼音近音、谐音、故事、场景、拆词/词根联想；内置示例为本项目原创，不复制墨墨背单词用户评论。
- 旧学习记录兼容：沿用 `wordmap_product_v21` 本地存储键与 `version:2` 状态结构；新增字段采用可选迁移。原 V3.2 JSON 备份可继续导入，新的导出备份增加 `mnemonics`。

## 运行方式
- 在线版：Vercel 静态站点，图片搜索需要网络；图片缓存后可离线查看。
- 单文件离线版：直接打开 `WordMap-Offline.html`，不加载 CDN、不依赖在线 TTS；网络图片搜索受浏览器 CORS 和网络状态影响。
- Go 便携版：启动本机 `127.0.0.1` 静态服务；目录中保留 `index.html`、`styles.css`、`data.js`、`app.js` 等资源即可独立运行。

## 图片来源与许可
- 图片搜索使用 Wikimedia Commons Action API；API 请求带 `origin=*`，只展示来源文件页及其可用的许可/作者元数据。
- 缓存图片时一并保存来源链接、许可和作者字段。许可信息缺失的图片会明确标记；使用者仍需在原始文件页确认具体许可条件。
- 图片缓存使用 IndexedDB；导出的 JSON 图片包包含图片数据与来源元数据，文件体积可能较大。

## 学习边界
- 汉语拼音近音只是记忆钩子，不是标准音标或标准英语发音；学生应先听标准英语，再使用联想。
- 拼写块沿用词库中的分块字段，不保证等于严格的英语音节或 IPA 音节。
- 记忆曲线图是示意图；实际复习队列按现有学习记录和到期时间生成。
- 153 条仍是可练习词条集合，不代表出版社已核验的官方完整词表。

## 技术结构
- 纯 HTML/CSS/JS，无 CDN、无远程 TTS、无后端数据库。
- 学习记录和自定义记忆卡保存在 localStorage；图片 Blob 保存在 IndexedDB。
- Go 启动器仅绑定本机回环地址。图片搜索为可选联网增强，不影响内网离线学习。

- Go 便携包构建脚本包含本地 Three.js 和世界场景文件；单文件离线版内嵌 Three.js、词库、业务逻辑和样式。

## V5.0 · 学生探索端与家长学习报告

- 学生端保留本地 Three.js 方块世界，重新整理任务栏、学习面板、例句和导航的布局，解决固定舞台与绝对定位造成的遮挡。
- 桌面、平板、手机采用不同布局策略；手机改为单列学习面板与横向单元列表。
- 家长端提供真实的掌握分布、今日作答、单元进度、错词关注、自定义词库、朗读设置和数据备份。
- 家长端与学生端共享当前浏览器中的 localStorage 数据；目前没有账号和云端同步，跨设备请使用 JSON 备份。
- 统一设计语言采用温和纸感底色、森林绿主色、清晰字号层级、统一圆角和轻量阴影；Three.js 场景仍为本地资源。


## V5.1 · 练习统计、动态词库与离线稳定性

- 练习统计按“每个单词练习一次”计数，连续多次误点不会重复增加作答次数或错词数；完成正确率的口径为已完成词数 / 总作答词数。
- 家长新增、删除自定义词，以及导入备份或清空数据后，图片词典和记忆中心的词条选择器会同步刷新。
- 删除当前自定义词、导入旧备份和清空记录时，重置练习上下文，避免残留旧词 ID、已使用字母和错误状态。
- JSON 备份下载延迟释放 Blob URL，减少部分浏览器下载尚未开始就撤销 URL 的风险。
- 家长端和后台标签页不再持续运行 Three.js 动画循环，减少无用 GPU/CPU 占用；切回学生端自动恢复。
- Service Worker 仅对导航请求回退首页，缺失的静态资源返回 503，避免把 HTML 错误地当作 CSS/JS 返回。
- 保持现有 localStorage 键、学习数据结构、词库、复习间隔、Three.js 和单文件离线发布方式不变。


## V5.1.1 · Go 便携发布包

### 构建

- Windows 10/11 x64：在 Windows 开发机运行 PowerShell 脚本 build/build-windows.ps1。
- macOS Apple Silicon：运行 bash build/build-macos-arm64.sh。
- Linux amd64：运行 bash build/build-linux.sh。
- 构建前如本机安装了 Node.js，会自动执行 tests/validate_v5_1.mjs；该测试只使用 Node 内置模块，不安装 npm 依赖。

### 发布产物

每个平台的 dist 目录包含平台 Go 启动器、静态网页资源、本地 Three.js、WordMap-Offline.html、使用说明、测试记录，以及 WordMap-V5.1.1-source.zip。另有一个平台运行包 ZIP，解压后即可运行。

### 运行时与数据

- 目标电脑不需要安装 Go、Node.js、Python、npm 或其他服务端运行时；Go 启动器为 CGO_ENABLED=0 编译。
- 页面 JavaScript 由电脑已有的 Chrome、Edge、Safari 或 Firefox 执行；不额外捆绑浏览器内核，避免把一个不到 1 MB 的学习应用变成几百 MB 的浏览器分发工程。
- Go 启动器仅监听 127.0.0.1:18765，固定端口用于保持浏览器 localStorage 的站点来源稳定，不开放局域网访问。
- 文字学习、拼写、记忆、家长端、3D 场景和已缓存图片均可在本机运行；Wikimedia 图片搜索需要网络，语音是否完全离线取决于操作系统英语语音包。
- 换浏览器、清理站点数据或换电脑前，使用家长端导出 JSON 备份。
