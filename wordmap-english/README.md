# 词汇星图 WordMap V3.1

## 产品定位
面向外研版（三起点）孙有中主编 2024版四年级上册的本地英语学习工具。保留 V2 的 113 个精选词、六单元关系图、鼠标拼字、键盘拼字、间隔复习和本机学习记录。

**词库边界：** 113 个词是精选练习词，不代表出版社官方完整词表。请按孩子手中的纸质课本逐页核对，确认后再作为正式词表。

## V3 新增
- 学习页进入新词时自动朗读英文单词，并可自动接着朗读原创拓展例句。
- 自动朗读开关、语速设置、手动重读单词、朗读例句。
- 独立“自动听写”页：按单元/错词/未掌握/全册筛选；每词朗读 1/2/3 次；键盘实时判定；答对自动下一词；暂停、继续、重播、结束。
- 每个词展示三类句子：课本原句（少量公开电子课本文本版摘句）、公开配套试卷预览摘句（附来源）、原创拓展例句（明确标注原创）。
- V2 `schema:21` 备份仍可导入；新备份为 `schema:22`。浏览器本地存储键不变，旧学习记录不迁移、不清空。
- 修复 V2 启动时引用不存在的 `unitGrid` 导致初始化中断的问题。



## V3.1 新增
- 自动听写增加“到期复习词”范围，可按全册或指定单元筛选。
- 首轮听写结束后，自动把本轮答错的词单独放入强化轮；不重做整套题，强化轮仍错的词会在结尾列出。
- 错词强化可关闭，设置保存在本机，并兼容旧备份。
- 增加 PWA 清单、图标和 Service Worker；在线版首次完整加载后可缓存静态资源，之后在支持 Service Worker 的浏览器中断网打开。
- 离线 Go 便携版仍直接从本地文件提供页面，不依赖 PWA 缓存，也不访问外网。

## 语音与离线边界
- 使用浏览器 Web Speech API 和系统已有的英语语音服务。
- 网页不下载语音、不调用在线 TTS API、不引用 CDN。
- 浏览器可报告 `localService`，但不能仅凭这一字段保证所有浏览器/系统都完全离线发声。目标 Windows 电脑必须安装可用的英语语音包，并在断网状态实测。
- 没有语音时，文字学习、拼写、复习记录仍可使用。

## 例句来源与真实性
- “课本原句”：目前 6 条短摘句来自 FlipHTML5 用户上传的公开电子课本文本版，不是出版社官方托管版本，建议与纸质课本复核。
- “公开配套试卷摘句”：目前 15 条来自教习网公开配套练习/试卷预览页，网页 OCR 有缺字，已按上下文校正；不是教育部门统一统考原卷，不标成正式统考真题。
- “原创拓展例句”：113 条由本项目编写，帮助理解单词用法，不冒充教材原文或真题。
- 未核验的课本原句不会由 AI 编造后贴上“原文”标签。

## Windows Go 便携版
1. 解压 `词汇星图-Windows便携版-V3.1.zip`。
2. 双击 `WordMap.exe`。
3. 程序仅监听 `127.0.0.1:18765`，不会向局域网开放。
4. 关闭启动器窗口即可停止本地服务。
5. 目标电脑无需安装 Go、Node.js、Python；需要 Windows x64 和可用浏览器。

也可以直接打开 `WordMap-Offline.html`。直接打开 HTML 与通过 Go 固定端口打开，浏览器可能使用不同的本机存储空间。

## 目录结构
- `index.html`：模块化网页入口
- `styles.css`：界面样式
- `data.js`：内嵌词库和例句数据
- `data/words.json`：可编辑词库 JSON
- `app.js`：交互、朗读和听写逻辑
- `launcher/main.go`：Go 本地启动器
- `dist/`：发布目录
- `WordMap-Offline.html`：单文件离线版本
- `manifest.webmanifest`、`sw.js`、`icon.svg`：PWA 安装和离线缓存
- `tests/validate_data.py`：词库、关系、来源和引用长度检查

## 构建
- Windows x64：`powershell -ExecutionPolicy Bypass -File .\build\build-windows.ps1`
- Linux x64：`bash ./build/build-linux.sh`
- macOS Apple Silicon（M 系列）：`bash ./build/build-macos-arm64.sh`
- 目标电脑无需 Go/Node/Python；Go 只在构建机上需要。macOS 启动器未做 Apple Developer 签名与公证，系统可能显示首次运行安全提示。

## 在线演示
同一套静态前端可部署到 Vercel 分享和演示。在线版不需要后端，也不是本地版的运行依赖。PWA 缓存逻辑已实现，适用于首次加载成功后的 HTTPS/localhost 环境；当前自动化环境未能完成断网重载实测，建议在目标浏览器验证。Windows Go 便携版本身不依赖 PWA。

## 已知限制
1. 113 个精选词不是出版社完整词表，教材准确性仍需纸书逐页核验。
2. 目前只有少量课本摘句和配套练习预览摘句。
3. 浏览器语音是否真正离线取决于目标机器语音包。
4. 学习记录保存在当前浏览器本地，不含云同步、账号和班级管理。
