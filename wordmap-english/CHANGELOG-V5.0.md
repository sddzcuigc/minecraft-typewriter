# WordMap V5.0 · 学生探索端与家长学习报告

## 本轮改动
- 修复固定舞台、全局 overflow:hidden 和多组 fixed 面板造成的遮挡、裁切问题。
- 学生端保留本地 Three.js 方块世界，重新整理任务栏、当前任务卡、学习面板、例句区和底部导航。
- 平板与手机改为顶部横向单元条和单列学习面板，允许内容滚动。
- 家长端提供词汇掌握结构、今日作答、单元进度、错词优先级、自定义词库、朗读设置和数据备份。
- 家长端统计只使用当前本机学习记录，不虚构学习时长、周趋势或跨设备同步数据。
- 继续使用本地 Three.js、原生 HTML/CSS/JS、localStorage 和 IndexedDB，不增加 CDN 或运行时依赖。
- Service Worker 缓存版本升级，避免旧缓存继续覆盖新版。

## 数据与兼容
- 保留 wordmap_product_v21 本地存储键及 version 2 学习状态结构。
- 不改动词库、单词关系、间隔复习规则和旧 JSON 备份格式。
- 家长端与学生端共享当前浏览器记录；跨设备仍需导出/导入 JSON。

## 离线发布
- WordMap-Offline.html 内嵌 HTML、CSS、Three.js、词库、业务逻辑和世界场景。
