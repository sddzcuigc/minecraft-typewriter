## 功能范围

- 拼音打字：中文释义 + 拼音近音钩子 + 拼写块提示，英文键入实时判定，无提交按钮。
- 拼音记忆：首批词条提供近音示例；所有词条均可在记忆中心自行编辑近音和联想。近音不是标准音标。
- 图片词典：Commons 图片搜索、原始文件页/作者/许可字段展示、IndexedDB 图片 Blob 缓存、JSON 图片包导入导出。
- 记忆中心：1/3/7/14/30 天复习间隔示意、真实到期复习队列、谐音/故事/空间/词根记忆卡。
- 兼容 V3.2：保留 localStorage key 和状态版本；旧 JSON 备份仍可导入，新增记忆卡纳入新备份。

## 离线边界与未实测项目

- 文字、拼写练习、记忆卡、复习队列和已缓存图片不依赖网络。
- 首次图片搜索需要网络；实际图片下载 CORS 仍需在目标浏览器实测。
- 记忆曲线是教学示意；实际复习队列由本机学习记录和到期时间决定。
- 拼音近音目前为首批示例，需继续逐词人工核校，避免错误近音固化。
- 尚未实测真实 Windows 断网朗读、IndexedDB 持久化、图片包跨设备恢复。
- 本轮更新了 Go 启动器所服务的静态资源，但尚未重新编译和打包 Windows/macOS Go 便携版。
