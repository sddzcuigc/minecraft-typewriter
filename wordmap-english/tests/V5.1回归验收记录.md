## 本轮修复

- [x] 每个单词练习只计一次作答；同一练习内多次误点只记一次出错词。
- [x] 完成正确率口径为已完成词数 / 总作答词数；家长端分别展示正确完成、出错词数和总作答。
- [x] 新增、删除自定义词、导入备份或清空记录后，图片词典与记忆中心选择器同步刷新。

## 人工验收（仍需真实设备）

- [ ] 新增自定义词后，在图片词典和记忆中心能立即选中；删除后列表不残留。
- [ ] 导入不含当前自定义词的备份后，不出现空白页或 JS 异常。
- [ ] 连续输入多个错误字母/点击多个错误拼写块，作答次数与出错词数仍只各增加一次。
- [ ] 完成同一词后，作答次数只增加一次；下一词复习正常。
- [ ] 家长端打开后 3D 场景停止动画；切回学生端恢复。
- [ ] 切换浏览器标签页到后台后暂停动画，返回后恢复。
- [ ] 断网刷新时首页能从 Service Worker 缓存加载；缺失资源不返回 HTML。
- [ ] JSON 导出/导入在 Chrome、Edge、Android 浏览器上可用。
- [ ] 真实 Windows、Mac、Android 设备检查 3D 性能和离线行为。
