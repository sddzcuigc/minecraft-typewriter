# WordMap V5.1

## 修复与优化

1. 练习统计按单词练习去重，错误事件不再重复累加同一次作答。
2. 家长自定义词库变更后，图片词典与记忆中心选择器同步更新。
3. 导入备份、删除当前自定义词、清空数据时重置练习上下文，避免旧词 ID 残留。
4. 备份下载延迟释放 Blob URL。
5. 家长端与后台标签页暂停 Three.js 动画，恢复前台/学生端后继续。
6. Service Worker 的离线 fallback 仅作用于导航请求，缺失静态资源返回 503。

## 兼容与离线

- 不更换 localStorage 键、学习记录 schema、词库和复习间隔。
- 同步更新源文件、Vercel public 发布副本和单文件离线 HTML。
- 不增加 CDN、npm 运行时或网络启动依赖。

## 验证

运行命令：node tests/validate_v5_1.mjs。真实设备、WebGL 与断网手工验收仍需在目标设备完成。
