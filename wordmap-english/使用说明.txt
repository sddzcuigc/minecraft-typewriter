词汇星图 WordCraft V5.1.1 · Go 便携版

【Windows 启动】
1. 解压 WordMap-V5.1.1-windows-amd64.zip。
2. 保持 WordMap.exe 与 index.html、app.js、data.js、world.js、styles.css、world-theme.css、vendor 目录在同一文件夹。
3. 双击 WordMap.exe，默认浏览器会打开 http://127.0.0.1:18765/。
4. 关闭 WordMap.exe 窗口即可停止本地服务。

【离线与运行时】
- 目标电脑不需要安装 Go、Node.js、Python、npm 或其他后端运行时。
- Go 启动器使用 CGO_ENABLED=0 构建；页面 JavaScript 由电脑已有的浏览器执行。
- 本地 HTML、CSS、JavaScript、153 个词条、Three.js 和 3D 场景随包分发，不加载 CDN。
- Go 服务固定只监听 127.0.0.1:18765，不向局域网开放。
- 直接打开 WordMap-Offline.html 也可使用单文件离线版；但 file:// 与 http://127.0.0.1:18765 使用的浏览器存储来源不同，建议日常使用 Go 启动器以保持学习记录稳定。
- 图片词典的在线搜索需要网络；已经缓存到 IndexedDB 的图片可离线查看。
- 语音依赖浏览器 Web Speech API 和系统英语语音包。无法保证每台设备的 TTS 都完全离线，需在目标设备断网实测。

【数据与备份】
- 学习记录保存在当前浏览器对 127.0.0.1:18765 的 localStorage；图片 Blob 保存在 IndexedDB。
- 家长端可导出/导入 JSON 学习记录备份；图片词典可单独导出/导入图片包。
- 固定端口用于保持同一浏览器中的数据来源稳定。不要随意换端口，否则浏览器会把它视为另一个站点。
- 更换浏览器、清理站点数据或换电脑前，请先导出备份。

【发布包内容】
- WordMap.exe：Windows x64 Go 本地启动器。
- WordMap-Offline.html：单文件离线版。
- vendor/three.min.js：本地 Three.js 引擎。
- WordMap-V5.1.1-source.zip：包含 HTML/CSS/JS、Go 启动器源码、构建脚本、词库、测试和许可证的源代码包。
- WordMap-V5.1.1-windows-amd64.zip：Windows 平台完整运行包。

【安全边界】
- 启动器仅绑定本机回环地址，不向局域网开放。
- 不包含账号、云同步或远程后台；学生端和家长端共享当前浏览器的本地记录。
- 如果 WebGL 不可用，文字学习面板仍可使用，但不会显示 3D 场景。
