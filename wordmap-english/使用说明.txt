词汇方块世界 WordCraft V4.0 · Windows 便携版

【启动】
1. 将整个 WordMap 文件夹解压到 Windows 10/11 x64 电脑。
2. 双击 WordMap.exe。
3. 程序会打开默认浏览器，访问 http://127.0.0.1:18765/。
4. 关闭 WordMap.exe 黑色窗口即可停止本地服务。

【离线与安全】
- 目标电脑不需要安装 Go、Node.js、Python 或 npm。
- 页面、词库、样式和交互代码均在本地。
- 在线版支持 PWA 静态资源缓存，首次加载后可在兼容浏览器断网打开；Go 本地版不依赖此功能。
- Three.js 0.159 已随程序放在 vendor 目录，不加载 CDN，不调用在线 TTS API。
- 3D 地形、方块、树木、建筑、云层和岛屿均由本地程序生成；不需要下载贴图。
- Go 服务固定只监听 127.0.0.1:18765，不向局域网开放。
- 公开课本/试卷来源链接只有在用户主动点击时才会打开外部网站。

【语音】
- 学习模式默认自动朗读单词，并可自动朗读原创拓展例句。
- 自动听写支持 1/2/3 次朗读、速度、暂停、继续、重播。
- 支持到期复习词筛选；首轮答错的词可自动进入一轮强化听写。
- 语音依赖浏览器 Web Speech API 和 Windows 英语语音包。
- 网页不下载语音，但无法保证每台 Windows 电脑的系统语音服务都完全离线；请断网实测。

【数据与备份】
- 学习记录保存在当前浏览器对 127.0.0.1:18765 的本地存储。
- 家长中心可导出/导入 JSON 备份。
- V2 schema 21 备份可导入；V3 新备份为 schema 22。
- 原 localStorage 键保持不变，升级时不会主动清空旧记录。
- 清理浏览器数据或更换电脑前，请先导出备份。
- 直接双击 WordMap-Offline.html 可能使用另一套浏览器本地存储。

【内容说明】
- 113 个精选词，六个单元，109 条词汇关联。
- 113 条原创拓展例句。
- 6 条公开电子课本文本版短摘句，建议与纸质课本复核。
- 15 条公开配套练习/试卷预览摘句，附来源；不等同于教育部门正式统考真题。
- 未核验的课本原句不会用 AI 编造冒充原文。

【macOS Apple Silicon（M 系列）】
- 可使用单独的 macOS ARM64 便携包，运行 WordMap-macos-arm64。
- 在终端进入解压目录，执行：chmod +x WordMap-macos-arm64 && ./WordMap-macos-arm64
- 浏览器访问 http://127.0.0.1:18765/。
- 当前二进制未进行 Apple Developer 签名与公证，macOS 可能显示首次运行安全提示；也可直接打开 WordMap-Offline.html 学习。

【3D 方块世界】
- 首次启动会在本机初始化 Three.js 场景，完全断网也可显示。
- 鼠标拖动旋转视角，滚轮缩放；点击六个浮岛切换学习单元。
- 如果设备不支持 WebGL，学习面板仍可使用，但不会显示 3D 场景。
- 在线图片词典仍是可选联网功能；其他学习流程不依赖外网。
