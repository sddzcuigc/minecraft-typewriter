# WordMap V3.1 更新记录

## 本轮新增
1. 自动听写新增“到期复习词”范围，可全册或指定单元筛选。
2. 自动错词强化：首轮结束后仅重练本轮错词，不重复整套；强化轮仍错的单词会列出。
3. 增加“错词自动再练一轮”开关，默认开启，设置写入本机学习数据。
4. 增加 PWA manifest、图标和 Service Worker。在线版首次成功加载后缓存核心静态文件，之后可在支持 Service Worker 的浏览器中离线打开。
5. Go 便携版保持固定 127.0.0.1:18765，只服务本地文件，不需要联网。

## 验收重点
- 单词答错后可退格修改，不显示答案。
- 首轮完成后只出现错词强化轮。
- 强化轮全部拼对后总结显示“强化后仍错 0 个”。
- 到期复习筛选只选择 `dueAt` 已到期、未稳定掌握且已解锁的词。
- 旧 V2/V3 学习备份仍可导入；新设置字段采用默认值兼容。
- PWA Service Worker 只缓存同源静态资源，不向外部域名发请求。

## 未改变
- 113 个精选词、六单元、109 条关联边。
- 简单模式鼠标点字母/拼写块，进阶模式键盘实时输入。
- 学习模式自动朗读，自动听写可配置朗读次数和速度。
- 课本原句、公开试卷预览句和原创拓展句继续分开标注，不混称。
